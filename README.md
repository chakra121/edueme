# 🎓 EduMe Research Labs - LMS Platform  
**Think. Create. Innovate.**  

EduMe Research Labs is a modern **Learning Management System (LMS)** designed to provide seamless learning experiences for students, teachers, and administrators.  
Built for real-time class management, student progress tracking, and payment-integrated course enrollment.

🔗 **Live Demo:** [EduMe LMS](https://edueme.vercel.app/)

---

## 🚀 Overview

EduMe LMS enables **schools, students, and teachers** to connect in a digital ecosystem focused on **STEM, Robotics, and AI learning**.  
It offers dedicated dashboards for **Admin**, **Teacher**, and **Student**, each with role-based features and secure authentication.

---

## 🧠 Dashboards

### 👩‍🎓 Student Dashboard
- Personalized greeting and learning progress display  
- **Course Progress** section  
  - Displays enrolled course name  
  - Tracks number of completed chapters  
- **Announcements** section  
  - Student updates and important notices from teachers/admin  
- **Upcoming Classes** section  
  - Displays scheduled live classes or alerts when no teacher is assigned  
- **Daily Classes**  
  - Students can join daily online live classes directly through the portal  
- Simple and interactive UI for better learning engagement  

---

### 👨‍🏫 Teacher Dashboard
- Manage and update **Course Catalog**  
- Add, update, or delete classes and chapters  
- Assign courses to specific student batches  
- View and manage student progress  
- Generate class links for live sessions  
- Streamlined layout for quick course editing and tracking  

---

### 🧑‍💼 Admin Dashboard
- Add and manage **Teachers**  
- Enroll **Students** into specific courses  
- Assign teachers to batches or subjects  
- Access to all system-level data and analytics  
- Manage **Announcements** and **Daily Class Scheduling**  

---

## 💳 Razorpay Integration
- **Secure payment gateway** integrated for course enrollment  
- Students can enroll in premium courses using Razorpay  
- Payment confirmation triggers automatic course assignment  

---

## 🧩 Key Features
- Role-based dashboards (Admin, Teacher, Student)  
- Razorpay Payment Integration for course enrollment  
- Real-time student progress tracking  
- Announcement & Notification system  
- Live class links and daily sessions  
- Course creation, update, and chapter management tools  
- Smooth and responsive UI built for all devices  
- Authentication & role-based routing  

---

## 🧱 Tech Stack
- **Frontend:** React.js, Next.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB / Firebase (depending on deployment setup)  
- **Payment Gateway:** Razorpay API  
- **Hosting:** Vercel
